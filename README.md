# NexusWeb Technologies ⚡

> **Estudio de Ingeniería de Software & Soluciones Web**  
> Proyecto desarrollado para la cátedra de **Tecnología Web**.

---

## 🚀 Acerca del Proyecto

**NexusWeb Technologies** es una plataforma web corporativa diseñada para presentar las capacidades, arquitectura técnica, proyectos y servicios de un equipo de desarrollo de software multidisciplinario.

Combina tecnologías web modernas, diseño vanguardista, interactividad 3D con Three.js y una experiencia fluida e inmersiva.

---

## 🛠️ Stack Tecnológico

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Librería UI**: [React 19](https://react.dev/)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones**: [Motion (Framer Motion v12)](https://motion.dev/)
- **Gráficos 3D**: [Three.js](https://threejs.org/) / `@react-three/fiber` / `@react-three/drei`
- **Iconografía**: [@phosphor-icons/react](https://phosphoricons.com/)

---

## 🌐 Servicios & Capacidades del Estudio

1. **Desarrollo Web & Móvil**: Arquitecturas Next.js y React 19, PWAs, APIs REST y GraphQL.
2. **Arquitectura Cloud & DevOps**: Despliegue automatizado CI/CD, Cloudflare R2, contenedores Docker.
3. **UI/UX & Sistemas de Diseño**: Prototipado de alta fidelidad, design tokens y accesibilidad WCAG.
4. **Automatización & Soluciones con IA**: Integración de LLMs, agentes conversacionales y automatización de flujos de trabajo.

## 👥 Estructura del Equipo

El proyecto cuenta con una organización por áreas técnicas especializadas:
- **Frontend Engineering Lead**: Arquitectura de interfaces reactivas, WebGL y rendimiento.
- **Backend & Cloud Architecture**: APIs distribuidas, persistencia de datos y seguridad.
- **UI/UX & Product Design**: Sistemas de diseño modulares, experiencia de usuario y prototipado.
- **DevOps & Quality Assurance**: Automatización de CI/CD, auditorías y pruebas de estabilidad.

## 💻 Instalación y Ejecución Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/omarapp19/tecnologiaweb.git
   cd tecnologiaweb
   ```

2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.
